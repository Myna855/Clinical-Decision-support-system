# Clinical Decision Support System using Explainable AI (XAI)

## Overview
This project develops an Explainable AI-based Clinical Decision Support System to predict hospital readmission risk among diabetic patients. It combines machine learning models with Explainable AI techniques to provide interpretable predictions and support clinical decision-making.

## Objectives
- Predict the risk of hospital readmission for diabetic patients.
- Apply machine learning techniques to improve prediction performance.
- Explain model predictions using Explainable AI techniques.
- Generate human-readable explanations using Large Language Models (LLMs).

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- SHAP
- LIME
- Large Language Models (LLMs)

## Key Features
- Data preprocessing and feature engineering.
- Hospital readmission risk prediction.
- Machine learning model training and evaluation.
- Explainability using SHAP and LIME.
- Identification of important factors influencing predictions.
- LLM-generated explanations of prediction results and feature attributions.

## Project Workflow
1. Data collection and loading.
2. Data preprocessing and cleaning.
3. Feature engineering and selection.
4. Machine learning model training.
5. Readmission risk prediction.
6. Model explanation using SHAP and LIME.
7. Generation of human-readable explanations using an LLM.

## Explainable AI
### SHAP
SHAP is used to identify the contribution of individual features toward a model prediction and understand the factors influencing readmission risk.

### LIME
LIME provides local explanations for individual predictions, helping interpret why a patient is classified into a particular risk category.

### LLM Integration
A Large Language Model converts prediction outputs and feature attribution results into understandable explanations, making model insights more accessible.
